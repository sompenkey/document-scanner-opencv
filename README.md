Smart Document Scanner using Computer Vision

Developed a real-time document scanner using Python, OpenCV, and NumPy capable of automatically detecting and extracting documents from images and webcam feeds.
Implemented Canny edge detection and contour approximation algorithms to identify document boundaries with high accuracy.
Applied perspective transformation (4-point transform) to generate a top-down scanned view from skewed images.
Enhanced scan quality using adaptive thresholding, sharpening filters, and noise reduction techniques.
Added support for both static image scanning and real-time webcam-based document capture with automatic saving and PDF export functionality.
